## Privacy policy

ROSHIQ does not send any data anywhere unless the user turns on online features in Settings.
When enabled, it requests public data from OpenDota (api.opendota.com), item icons from Valve's CDN
and release information from GitHub. All network requests are listed in the app's network log.
Game data comes only from Dota 2 Game State Integration (an official Valve mechanism) on the local computer.

## Releases

Signed binaries are built by GitHub Actions from this repository and published in GitHub Releases.
