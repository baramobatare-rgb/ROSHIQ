    Что внутри

    От первого пика до следующего матча — помощь на каждом этапе.

    Драфт

    Контрпики и героев в связку под твою роль, с коротким «почему». Учитывает, на ком ты играешь чаще всего.

    Панель в игре

    Прозрачная панель поверх Dota: руны, Рошан, ТП, тайник, выкуп. Мышь проходит сквозь неё — в игре не мешает.

    Разбор матча

    Что получилось и одна главная ошибка. Керри сравнивается с керри, саппорт — с саппортом, и только по твоим играм.

    Сборки и тайминги

    Предметы по фазам игры, что сейчас собирают чаще всего, и твои собственные тайминги ключевых предметов.

    Цели

    Одна конкретная цель на следующую игру — и история, по которой видно, получается ли её держать.

    Без возни

    Сам прячется при запуске Dota, сам определяет роль и обновляется одной кнопкой, без переустановки.

    Твои данные.
    Понятные правила.

    Время матча, героя, золото и инвентарь ROSHIQ получает через Game State Integration — интерфейс самой Dota 2. Автодрафт распознаёт видимые портреты героев на экране выбора. Публичная статистика OpenDota подключается по желанию.

    Делает

    • получает данные, которые игра отправляет сама
    • показывает подсказки поверх игры и в своём окне
    • по желанию берёт публичную статистику OpenDota
    • хранит всё у тебя на компьютере

    Не делает

    • не читает память игры и не внедряет код
    • не нажимает клавиши и не управляет героем
    • не показывает то, что скрыто от тебя в игре
    • не просит пароль от Steam

    ROSHIQ — независимый проект с открытым кодом. Valve его не проверяла и не одобряла. Устройство программы можно проверить в исходниках.

    Если что-то не так

    Windows пишет «Компьютер защищён»

    Нажми «Подробнее» → «Выполнить в любом случае». У программы пока нет платной цифровой подписи, поэтому Windows её не узнаёт. Файл можно сверить с SHA256SUMS.txt на странице релиза.

    Подсказки в игре не появляются

    Открой Настройки → Диагностика. Она проверит связь с игрой, порт и параметр запуска -gamestateintegration — рядом с проблемой будет кнопка «Исправить». Потом перезапусти Dota 2: связь включается только при запуске игры.

    Панели не видно поверх игры

    Переключи Dota 2 в режим «Окно без рамки» (Настройки → Видео). Поверх полноэкранного режима прозрачные окна не рисуются. Показать или скрыть панель — F8.

    Как привязать Steam

    Обычно ничего делать не нужно: после первого матча аккаунт привяжется из игры сам. Или Настройки → Steam: «Найти Steam на этом ПК» либо «Войти через Steam» — вход идёт на сайте Steam, пароль ROSHIQ не видит.

    Матчи и статистика не подтягиваются

    OpenDota не видит скрытую историю. В Dota 2: Настройки → Параметры → Социальные → включи «Общедоступная история матчей», сыграй матч и обнови профиль в ROSHIQ.

    Ничего не помогло

    Настройки → Диагностика → «Собрать отчёт» — один zip с журналами, без Steam ID и ключей. Пришли его в сообщения группы ВКонтакте и опиши, что случилось.

    Вопросы

    Нужен ли интернет?

    Нет. Без интернета работают драфт, сборки, таймеры, подсказки и итог матча. Интернет нужен для статистики OpenDota и обновлений, его можно выключить одной галочкой.

    Сколько стоит?

    Нисколько. Ни подписок, ни рекламы, ни платных функций. Код открыт — любой может посмотреть, что внутри.
