02 · БЕЗ БАНА

Честно — значит по правилам

Dota 2 сама отправляет ROSHIQ время матча, героя, золото и инвентарь через Game State Integration — официальный механизм Valve, который используют стримерские оверлеи.

Что делает

  • ✓получает данные, которые Dota 2 отправляет сама;
  • ✓показывает подсказки поверх игры и в своём окне;
  • ✓по желанию берёт публичную статистику OpenDota;
  • ✓хранит историю и настройки у тебя на компьютере.

Чего не делает

  • ✕не читает память игры и не внедряет код;
  • ✕не нажимает клавиши и не управляет героем;
  • ✕не использует скрытую от тебя информацию;
  • ✕не просит пароль Steam.

04 · FAQ

Частые вопросы

Не забанят?

ROSHIQ использует только Game State Integration — официальный способ, которым Valve разрешает программам получать данные из Dota 2. Программа не трогает файлы игры (кроме файла настройки GSI в папке cfg), не читает память и ничего не нажимает. При этом ROSHIQ — неофициальный проект и не одобрен Valve.

Нужен ли интернет?

Нет. Без интернета работают драфт по правилам, сборки, таймеры, подсказки и итог матча. Интернет добавляет статистику OpenDota, мету, разбор матчей и обновления.

Оверлей не виден поверх игры

Включи в Dota 2 «Окно без рамки» (Настройки → Видео). В эксклюзивном полноэкранном режиме прозрачные окна поверх игры не отображаются.

Это правда бесплатно?

Да. Без подписок, рекламы и платных функций. Исходный код открыт на GitHub — любой может проверить, что внутри.

Windows пишет «защитила ваш компьютер»

Нажми «Подробнее» → «Выполнить в любом случае»: у программы пока нет платной цифровой подписи. Целостность файла можно проверить по SHA256SUMS.txt в релизе.
